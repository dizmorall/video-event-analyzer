# Video Event Analyzer (Система анализа видеофайлов и формирования текстового описания событий)

Курсовой проект по дисциплине «Программирование / Анализ данных»  
**Учреждение образования «Брестский государственный технический университет» (БрГТУ)**  
**Факультет электронно-информационных систем (ФЭИС)**  

---

## О проекте
Программный комплекс предназначен для автоматической обработки видеопотока со статичных камер наблюдения, детекции и трекинга ключевых объектов («человек», «транспортное средство»), а также логического анализа их поведения в зонах интереса (ROI) и на виртуальных линиях контроля. На выходе система формирует структурированное текстовое описание происходящих событий и предоставляет REST API для интеграции.

## Ключевые возможности
- **Детекция объектов:** Использование современных моделей семейства **YOLO** для обнаружения людей и транспорта.
- **Трекинг:** Стабильное отслеживание траекторий с помощью алгоритмов **ByteTrack** / **BoT-SORT**.
- **Модуль событийной логики (Event Engine):**
  - Контроль пересечения виртуальных линий (Tripwires).
  - Отслеживание входа/выхода из полигональных зон интереса (ROI).
  - Детекция остановки движения / длительного нахождения в зоне.
- **REST API:** Интерфейс на **FastAPI** для управления задачами анализа и получения отчетов.
- **Хранение данных:** Реляционная СУБД **PostgreSQL** для сохранения метаданных видео, треков, детекций и зафиксированных событий.
- **Отчетность:** Генератор структурированных текстовых и JSON-отчетов по результатам обработки видеофрагментов.

## Технологический стек
- **Язык программирования:** Python 3.11 / 3.12
- **Computer Vision & Deep Learning:** OpenCV, PyTorch, Ultralytics YOLO
- **Tracking:** ByteTrack / BoT-SORT
- **Backend / API:** FastAPI, Uvicorn
- **База данных:** PostgreSQL, SQLAlchemy / Alembic
- **Тестирование и метрики:** Scikit-learn (Precision, Recall, F1-score), NumPy

## Архитектура программного комплекса
*(Здесь планируется разместить диаграмму компонентов)*
1. **Video Ingestion Pipeline:** Загрузка и кадровая нарезка видео (720p–1080p, 15–30 FPS).
2. **Inference Core:** Детекция + Трекинг кадра за кадром.
3. **Event Engine (State Machine):** Конечный автомат, определяющий геометрию пересечений и логику событий.
4. **Storage & API Layer:** Запись в PostgreSQL и выдача результатов через FastAPI.
